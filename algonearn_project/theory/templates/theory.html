Типы данных

В программировании типы данных делятся на простые и структурированные. Простые типы хранят одно значение (число, символ, логическое значение), а структурированные — набор значений, объединённых по какому-либо принципу.

Простые типы

  • Целые числа (int)
  • Вещественные числа (float)
  • Символы (char)
  • Логический тип (boolean)

Структурированные типы

  • Массивы — упорядоченные наборы
  • Структуры (записи)
  • Множества
  • Файлы

💡 Ключевая идея: Массив — самый простой и распространённый структурированный тип данных. Это фундамент, на котором строятся более сложные структуры.

Массивы

Массив — это упорядоченный набор однотипных элементов, каждый из которых имеет свой номер (индекс). Нумерация обычно начинается с 0.

[0]42
[1]17
[2]8
[3]35
[4]91
[5]3
[6]56

Характеристики массива

  • Индекс — номер элемента (начинается с 0)
  • Длина — количество элементов
  • Тип элементов — все элементы одного типа

Виды массивов

Одномерные — линейная последовательность элементов. Используются чаще всего.

# Python
arr = [10, 20, 30, 40, 50]
print(arr[2])  # 30

Двумерные (матрицы) — таблица строк и столбцов. Используются для матриц, таблиц.

# Python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
print(matrix[1][2])  # 6

Основные операции (Python)

# Создание массива
arr = [64, 34, 25, 12, 22, 11, 90]

# Длина массива
print(len(arr))  # 7

# Доступ по индексу
print(arr[0])    # 64

# Поиск элемента
idx = arr.index(25)  # 2 (индекс элемента)

# Сумма элементов
total = sum(arr)     # 258

# Минимум и максимум
minimum = min(arr)   # 11
maximum = max(arr)   # 90

Зачем сортировать?

Сортировка — это процесс упорядочивания элементов по возрастанию или убыванию. Это одна из самых важных операций в информатике.

🔍 Быстрый поиск

В отсортированном массиве можно искать элементы в разы быстрее (бинарный поиск).

📂 Удобство

Отсортированные данные проще анализировать и воспринимать.

📊 Статистика

Нахождение медианы, квартилей и других статистик требует сортировки.

Пример: до и после сортировки

До:

64 34 25 12 22 11 90

После:

11 12 22 25 34 64 90

Алгоритмы сортировки

🫧 Сортировка пузырьком (Bubble Sort)

Самый простой алгоритм. Сравнивает соседние элементы попарно и меняет их местами, если они стоят не в том порядке. Большие элементы «всплывают» к концу массива, как пузырьки.

# Python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n - 1):
        for j in range(n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
    return arr

Сложность: O(n²) | Простота: ★★★ | Скорость: ★☆☆

👆 Сортировка выбором (Selection Sort)

На каждом шаге находит минимальный элемент в неотсортированной части и ставит его на своё место.

# Python
def selection_sort(arr):
    n = len(arr)
    for i in range(n - 1):
        min_idx = i
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr

Сложность: O(n²) | Простота: ★★★ | Скорость: ★☆☆

📥 Сортировка вставками (Insertion Sort)

Берёт каждый следующий элемент и вставляет его на правильное место среди уже отсортированных. Как сортировка карт в руке.

# Python
def insertion_sort(arr):
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1
        arr[j + 1] = key
    return arr

Сложность: O(n²) | Простота: ★★☆ | Скорость: ★★☆

📊 Сравнение алгоритмов

Алгоритм Лучший случай Средний случай Худший случай Память
Пузырьком O(n) O(n²) O(n²) O(1)
Выбором O(n²) O(n²) O(n²) O(1)
Вставками O(n) O(n²) O(n²) O(1)
